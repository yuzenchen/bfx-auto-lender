# 策略設定說明

本文件說明儀表板「策略設定」面板中每個欄位的意義，以及機器人的運作邏輯。

## 基本觀念

- **放貸（Funding）**：把 USD 借給 Bitfinex 上做槓桿交易的人收利息，到期還本，由交易所撮合與保證，不需對手方信用風險判斷。
- **日利率 vs 年化**：Bitfinex 的利率以「日利率」計價（例：日利率 0.03% ≈ 年化 10.95%）。介面輸入一律用**日利率 %**，旁邊會即時換算年化（× 365）給你參考。
- **FRR**（Flash Return Rate）：市場的浮動參考利率。
- **24h 最高日利率**：過去 24 小時內市場成交過的最高日利率——**本機器人的核心判斷依據**。利率每天會有數波高峰，策略目標是把單掛在高峰附近成交。
- **掛單（Offer）→ 成交（Lent）**：掛出的是限價單，利率漲到你的掛單價才成交；成交後開始按日計息，到期資金自動回到可用餘額，機器人會再次自動掛出。

## 機器人每輪的運作流程

每個「檢查週期」執行一次：

```
1. 讀取可用餘額
2. 檢查過時掛單：掛超過「重掛判定」時數未成交、且利率已高於目前目標
   → 取消，下一輪用新利率重掛
3. 判斷：24h 最高日利率是否落在你設定的〔下限, 上限〕範圍內？
   ├─ 否 → 本輪不掛單（日誌記錄原因）
   └─ 是 → 掛單利率 = 24h 最高 × 掛單利率比例（但不低於下限）
4. 可掛金額 = 可用餘額 − 保留金額（不足 150 USD 則本輪不動作）
5. 依「單筆掛單金額」拆分掛出；低於「小額門檻」的掛單改用小額規則
```

## 欄位說明

### 啟用自動出借
總開關。勾選＋儲存後，機器人啟動時才會實際掛單；未勾選時機器人照常輪詢但不動作。
（右上角的「啟動／停止」控制機器人本身是否運行，兩者都開才會自動出借。）

### 日利率範圍下限（%）
可接受的最低日利率。**24h 最高日利率低於此值時，本輪完全不掛單**，等市場回升。
同時它也是掛單利率的地板——依比例折算後的掛單利率不會低於這個值。

> 例：設 0.02（年化 7.3%）。若市場 24h 最高只有 0.015%，機器人會一直等待，不會用低利率把資金鎖住。

### 日利率範圍上限（%）
可接受的最高日利率。24h 最高**超過**上限時也不掛單——用途是「利率異常飆高時保持觀望」（極端行情常伴隨劇烈波動）。若你想「越高越好」，把上限設大（例如 1–2%）即可，幾乎不會觸發。

### 掛單利率比例（% of 24h 最高）
掛單利率 = 24h 最高日利率 × 此比例。

- **100**：掛在 24h 最高點，收益最大化但要等利率再次衝到高點才成交，可能等很久
- **95（預設）**：稍微讓利，大幅提高成交機率，長期通常總收益更好
- 越低成交越快、單筆利率越低，自行取捨

> 例：24h 最高 0.04%、比例 95 → 掛 0.038%。

### 出借天數（2–120）
成交後資金被鎖定的天數，Bitfinex 允許 2–120 天。

- **短天期（2–7 天）**：資金靈活，利率漲了可以很快換約跟上
- **長天期（30–120 天）**：把當前利率鎖久一點，適合在利率高點時使用

常見做法：平時用短天期，看到利率飆高時手動改長天期鎖住。

### 單筆掛單金額（USD，0 = 不拆分）
把資金拆成多筆掛出。0 = 全部一筆掛出。

拆分的好處：部分成交機率較高、到期時間錯開、資金回流較平滑。拆分後的尾數若不足 150 會自動併入最後一筆。每輪最多掛 10 筆。

### 小額門檻（USD，0 = 停用）／小額出借天數
**小額掛單特別規則**：當某筆掛單金額低於門檻時，改用「小額出借天數」、並以**市場最佳出借利率**掛出（不套用 24h 最高與下限地板），目標是讓零碎資金快速成交、不閒置。

> 例：門檻 500、小額天數 3 → 到期回流的 300 USD 零頭會以市價掛 3 天，很快借出去繼續生息。

### 保留金額（USD）
永遠不出借的金額，留在可用餘額裡（例如準備提領或手動操作的預備金）。

### 檢查週期（分鐘）
機器人多久跑一輪。預設 5 分鐘；資金量大、想快速跟上利率波動可設 1–2 分鐘，佛系一點設 30–60 分鐘也可以。

### 掛單重掛判定（小時）
掛單超過此時數仍未成交、**且**其利率已高於目前的目標掛單利率（代表高點已回落、繼續掛也不會成交）時，自動取消重掛。

- 設太短：頻繁取消重掛，可能在利率即將衝高前把單撤掉
- 設太長：利率下跌後資金卡在高利率掛單上空轉
- 建議 1–24 小時之間，預設 1 小時

## 建議起手設定（穩健型）

| 欄位 | 建議值 | 理由 |
|---|---|---|
| 日利率下限 | 0.02（年化 7.3%） | 低於這個水準寧可等 |
| 日利率上限 | 1.0 | 幾乎不設限，僅防極端 |
| 掛單利率比例 | 95 | 收益與成交率的平衡點 |
| 出借天數 | 2 | 保持靈活 |
| 單筆掛單金額 | 0 或 3000–5000 | 資金大再拆分 |
| 小額門檻／天數 | 500／2 | 零碎資金快速去化 |
| 保留金額 | 0 | 有提領需求再設 |
| 檢查週期 | 5 | 預設即可 |
| 重掛判定 | 1–4 | 依市場波動調整 |

## 常見問題

**Q：為什麼掛單一直不成交？**
掛單利率是「24h 最高 × 比例」，本來就要等利率波動到高點附近。觀察「動作日誌」與掛單時間，若持續超過一天不成交，考慮調低掛單利率比例（如 90）。

**Q：為什麼機器人一直顯示「本輪不掛單」？**
看日誌原因：多半是 24h 最高不在你設定的範圍內（下限設太高），或可用餘額不足 150 USD。

**Q：到期後會自動續借嗎？**
會。到期資金回到可用餘額，機器人下一輪檢查時自動重新掛出。

**Q：我可以手動取消掛單嗎？**
可以，掛單表的「取消」按鈕隨時可用；取消後資金回到可用餘額，機器人下一輪會依策略重新掛出（不想被重掛就先停止機器人或關閉啟用開關）。

**Q：改設定需要重啟嗎？**
不用，按「儲存設定」即生效，下一輪檢查就會採用新參數。
